# Security policy

## Supported versions

Security fixes are currently provided for the latest version on the default
branch. Older pre-release builds may not receive backports.

## Reporting a vulnerability

Please do not disclose an unpatched vulnerability in a public issue. Use a
private repository security advisory if available, or contact the project
maintainers privately with:

- a concise description and impact;
- affected version and platform;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation.

We will acknowledge a valid report, investigate it, and coordinate disclosure
after a fix or mitigation is available. Do not include passwords, API keys, or
real user data in a report.
