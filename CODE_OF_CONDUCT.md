# Code of Conduct

## Our pledge

We are committed to making participation in KET Studio welcoming, respectful,
and harassment-free for everyone, regardless of background, identity,
experience, or skill level.

## Expected behavior

- Be respectful and constructive.
- Welcome beginners and explain technical decisions clearly.
- Focus feedback on the work, not the person.
- Accept corrections and changing evidence in good faith.

## Unacceptable behavior

Harassment, discrimination, intimidation, personal attacks, sexualized
language or imagery, doxxing, and any other conduct that would make a
reasonable participant feel unsafe are not acceptable.

## Enforcement

Project maintainers may remove comments, close discussions, or restrict
participation when this code is violated. Report concerns privately through a
GitHub security/private report or directly to the maintainers. Reports will be
handled as confidentially as practical.

This code is adapted from the Contributor Covenant community standard.
